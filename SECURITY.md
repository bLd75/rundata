# Sécurité

Une faille dans le serveur MCP, le site rundata.re ou ce dépôt ? Merci de la signaler en privé, pas dans un ticket public :

- sur GitHub, onglet **Security**, bouton **Report a vulnerability** ;
- ou par courriel à contact@rundata.re.

Je réponds sous une semaine. Seule la dernière version, celle en ligne sur rundata.re, reçoit des correctifs.

## English

Please report vulnerabilities privately: **Security** tab, **Report a vulnerability**, or email contact@rundata.re. Only the latest version, the one running on rundata.re, gets fixes.
